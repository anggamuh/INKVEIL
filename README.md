# INKVEIL

Beyond the pages.

A Go-based comic reading platform for original and authorized third-party content.

## Release candidate

Run `go test ./...`, `go vet ./...`, then `go run .` locally. See [release checklist](docs/release-checklist.md), [source pipeline](docs/package-pipeline.md) and `/admin/team` for the internal workflow. v1.0 RC is not yet production-verified.
