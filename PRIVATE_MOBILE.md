# Private mobile test
For content you have permission to access remotely, use -PrivateMobile with the existing authorized source flags. Set a unique password of at least 16 characters when prompted. All INKVEIL routes require HTTP Basic authentication (username inkveil); this includes images and API routes. Use HTTPS via a private authenticated tunnel, never expose Suwayomi port 4567. Stop the tunnel after testing. Existing local mode is unchanged. The image bridge permits only configured local Suwayomi thumbnails and short-lived chapter image grants produced by the existing validated reader, with size, MIME and concurrency bounds. No arbitrary URL forwarding. Basic auth is independent of reader accounts. No public redistribution or access bypass. Go/browser tests not run.
