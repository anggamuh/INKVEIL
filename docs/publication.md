# Chapter publication metadata

New manual uploads get a UTC publication timestamp. Authorized manifest imports preserve supplied RFC3339 PublishedAt values; if omitted, new chapters get their first local import time, not the original source release time. Existing chapters without a timestamp remain unknown and do not receive a fabricated release date or NEW label. NEW means published locally or supplied publication time within the past 24 hours. The JSON editor can backfill known timestamps; timestamps more than five minutes in the future are rejected. Default discovery sorting uses the most recent known publication date per comic; chapter display sorts by publication date, while reader previous/next continues to use original chapter order. No schema migration is necessary because catalog metadata is stored in JSON payloads. This is not scheduled publishing or draft workflow.
