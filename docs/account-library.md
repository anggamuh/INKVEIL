# Account library

MySQL startup adds inkveil_bookmarks and inkveil_history. Log out and log in again after upgrading to replace the old /account-scoped session cookie. Signed-in readers use server-side bookmarks and latest chapter per comic; guests retain their existing browser-local library. Guest data is deliberately not imported automatically to avoid leaking shared-browser history into another account. Reader width stays device-local. Account library API uses session authentication, same-site cookies, JSON requests with custom header and no CORS support. Limits: 500 bookmarks, 100 recent comics. On sync failure, reload rather than silently writing account data to guest storage. No exact scroll tracking or offline account edits. Test live login and cross-device sync before production.
