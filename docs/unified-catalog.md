# Unified catalog engine

Opt-in indexed discovery: with existing MySQL configuration, run `go run . refresh-catalog` then set `INKVEIL_UNIFIED_INDEX=yes` and start normally with MangaDex. Index contains up to 1000 recent MangaDex titles per language and up to 10000 supplemental entries per language, not the full MangaDex catalog. Default live search remains available via source=MangaDex. Snapshot expires after seven days; refresh manually; failed refresh leaves prior snapshot intact. Local catalog takes priority, then MangaDex, then one optional supplemental adapter. Matching requires normalized title/alias and matching nonempty author, compatible type/year; ambiguous records remain separate. Stable provider URLs remain; canonical IDs and cross-provider library migration are not implemented. Supplemental adapter requires an authorized HTTPS API implementing /catalog?lang=&cursor=, /titles/{id}, /titles/{id}/chapters/{chapter}, with JSON fields matching live.go. Set INKVEIL_EXTRA_PERMISSION=yes only with permission, INKVEIL_EXTRA_URL and INKVEIL_EXTRA_IMAGE_ORIGIN. No RuangKomiku-specific integration, cover proxy, or supplemental account history yet. No reader selector. Tests not executed.
