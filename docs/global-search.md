# Global search
Enable only sources whose content and API usage you are authorized to integrate. Pass their source IDs to start.ps1 with -AuthorizedSearchSources "123,456" (example IDs). The existing library switch is independent. Search queries request the first page from up to three explicitly configured Indonesian sources through the local Suwayomi API, merge with library and MangaDex results, and cache one successful query for 60 seconds. No automatic library writes or full catalog crawling. Titles not yet initialized load missing metadata and chapters on opening. The internal reader retains its existing chapter membership and page-path validation. Server version compatibility and live integration still require local testing. No credentials committed.
