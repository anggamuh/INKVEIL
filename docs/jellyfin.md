# Jellyfin catalog adapter
Install Jellyfin on the same computer (http://127.0.0.1:8096), create a dedicated anime TV Shows library containing authorized media, and let Jellyfin scan its metadata. Configure INKVEIL_ANIME_PERMISSION=yes, INKVEIL_JELLYFIN_PERMISSION=yes, INKVEIL_JELLYFIN_LIBRARY (32-character library ID), INKVEIL_JELLYFIN_USER (32-character user ID), and INKVEIL_JELLYFIN_TOKEN (token for an account restricted to the anime library). Do not commit or paste the token. Requests stay on fixed loopback, no redirects; series membership is checked for poster and episode access. Katalog and poster use Jellyfin metadata; maximum 500 series and 500 episodes per series. No streaming bridge, transcoding, subtitle integration, cross-device watch state or Jellyfin remote login in this batch. Jellyfin playback uses its own client. The existing local MP4 player remains independent. Private mobile authentication still required for tunnel access. Live Jellyfin and Go tests not executed.
