# Structured metadata catalog scraper

Optional Indonesian catalog source, integrated into refresh-catalog after existing provider priorities. Accepts public JSON-LD ComicSeries/BookSeries/ComicStory records on explicitly configured HTTPS catalog pages. No JavaScript execution, cookies, authentication, redirects, challenge bypass, chapter extraction or image mirroring. Cards link directly to their source. Only configure pages whose operator permits automated metadata retrieval and whose robots rules allow the configured URLs. Set INKVEIL_SCRAPE_PERMISSION=yes and INKVEIL_SCRAPE_CATALOG_URLS to whitespace-separated approved URLs (max 20). Run refresh-catalog with MySQL and enable INKVEIL_UNIFIED_INDEX=yes. A blocked/unsupported response aborts refresh and preserves previous snapshot. Existing conservative deduplication requires author evidence, so ambiguous duplicates may remain. Shinigami compatibility unverified; no specific selectors assumed. Tests added but not executed.
