# Personal suite

MangaDex bookmarks, history, last chapter and read markers are stored in this browser, separately from existing account-backed Original Project data, displayed together in Library. Read marker means final page loaded, not verified reading completion. Continue Reading on discovery shows MangaDex history. Update notices compare latest chapter IDs when revisiting a bookmarked detail in the same language; no background notifications. Popular sort uses MangaDex followedCount, not local ranking. Genre filter uses provider tag IDs and switches mixed catalog to MangaDex-only; Original Project keeps its existing text search. Featured rail uses current catalog, not personalized recommendations. Reader quality persists in browser. Provider configuration remains environment-based with existing source filter. Image transport unchanged. No browser or Go suite execution performed.
