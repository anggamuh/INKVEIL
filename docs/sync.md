# Scheduled manifest sync

Disabled by default. Set INKVEIL_SYNC_URL to an HTTPS JSON manifest endpoint controlled or explicitly trusted by the operator, INKVEIL_SYNC_SOURCE to the source label, INKVEIL_SYNC_PERMISSION=yes only after obtaining publication permission, and optionally INKVEIL_SYNC_INTERVAL=30m (5m–24h). Restart the server. Sync runs immediately and then at the interval, with a 20-second HTTP timeout, a 4 MiB response limit, and no redirects. The operator must not expose endpoint configuration to untrusted users or configure untrusted/internal services. This is metadata and local-file-reference synchronization; remote image fetching is not implemented. Existing chapters and metadata remain unchanged; new images referenced by chapters must already be in the pages directory. Failures are logged to the server console. Successful changing imports are recorded in imports.jsonl. Single process only.
