# Local MangaDex reader (experimental)

Set INKVEIL_LIVE_PROVIDER=mangadex and INKVEIL_DEX_READER=yes for noncommercial personal testing under MangaDex terms. Homepage and /live show catalog; chapter pages render directly using MangaDex@Home URLs (data saver preferred). No remote image downloads to disk, no proxy, no bypass of provider controls. Attribution shown. INKVEIL_DEX_BLOCKED_GROUPS accepts comma-separated group UUIDs for removal requests. Navigation is limited to current feed page. Cover art and live bookmarks remain pending. Direct browser image loads may be rejected by the provider and cannot reliably read network reporting headers; full @Home reporting compliance has not been verified, so do not deploy this experimental reader publicly. External-only chapters remain unavailable. No live API smoke test performed.
