# Recent releases
The unfiltered latest view reads the first 100 available MangaDex chapter records for the requested language, then batches title metadata, and combines them with up to 100 stored Suwayomi chapter records ordered by upload date. Only enabled Indonesian Suwayomi sources and permitted titles are included. Release timestamps, not title edits or chapter number, determine order; unknown/future timestamps are excluded. Cache: 60 seconds on successful results. Results are bounded and are not a complete global catalogue. Suwayomi data freshness depends on its existing update process; no automatic extension crawling. Filters for genre and Original Project remain ordinary catalogue views. Shared Obsidian footer on public browsing pages, excluded from immersive reader. Tests added; Go and browser verification not performed.
