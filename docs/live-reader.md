# Live reader foundation

Separate /live catalog, title detail and reader routes for a provider that permits third-party display. Set INKVEIL_LIVE_PERMISSION=yes only after confirming permission, INKVEIL_LIVE_URL to the approved HTTPS API base, and INKVEIL_LIVE_IMAGE_ORIGIN to its approved HTTPS image origin. The provider contract is GET /catalog?q=&cursor= returning {Items:[{ID,Title,Description,Genre,Type}],Next:""}; GET /titles/{id} returning {ID,Title,Description,Genre,Type,Chapters:[{ID,Number}]} in reading order; GET /titles/{id}/chapters/{chapter} returning {Images:["https://approved-origin/page.jpg"]}. This is a generic contract, not a Shinigami-specific adapter. No images or catalog written to storage. Cache one minute, bounded entries and concurrency; redirects disabled. Configure trusted public endpoints only; network egress policy is needed before deployment. Existing local projects remain separate. No live bookmarks, covers, unified ranking or full provider-specific filters yet. Tests added but not executed.
